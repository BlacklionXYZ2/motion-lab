# From SORA

Copies of SORA's avatar-player code (`../SORA/clients/unity/Assets/Scripts/Avatar`), shared by the
motion environment: hair, clothing and accessories (roadmap MA, A1). **SORA's files are the source
of truth.** Don't edit these; change SORA's and run `scripts/sync-from-sora.ps1`. A test fails if
they drift.
