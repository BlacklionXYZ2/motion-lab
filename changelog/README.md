# motion-lab changelog

One file per change to motion-lab: its versions, data, training, evaluation, tools and the
external models it tests. Same rules and file-name format as SORA's
[changelog](../../SORA/changelog/README.md): one file per change, in the contributor's own model
name, and never edit or rename another contributor's entry.

**Which folder:** work done in motion-lab is logged here. A change to SORA itself is logged in
SORA's `changelog/`, even when it comes from motion-lab work, for example:
- the physics body or avatar layer synced into SORA's player;
- the motion-core roadmap in `SORA/docs/plans/`;
- the brain's motion keywords.

**History:** the first 21 entries here (2026-10-11 to 2026-10-26) were written in SORA's
`changelog/` and moved here on 2026-10-26 at the owner's request ("There's 230 changelogs now
and it's going to become more and more challenging to separate them"). Their file names and
contents are unchanged, except that three links now point to `../../SORA/docs/`. The motion
entries that changed SORA stayed in SORA.
